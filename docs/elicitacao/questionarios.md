# Questionários de levantamento de requisitos

Sistema web de feedback e desenvolvimento de competências.

O instrumento, com nome, telefone e função em branco, está em [questionario-elicitacao.md](questionario-elicitacao.md). Ele foi montado a partir da [síntese da entrevista](sintese-requisitos-entrevistas.md) com Adriana Silveira de Souza. As duas aplicações pedidas pela disciplina ainda não foram feitas. Quem responder precisa ser uma pessoa diferente da entrevistada.

Cada aplicação preenche uma cópia do instrumento. O registro abaixo guarda só a identificação, para a entrega. As respostas ficam na cópia.
