# Questionário de elicitação — base

Instrumento para levantar requisitos do sistema de feedback e gestão de competências com pessoas que não deram a entrevista. A base foi montada a partir da [síntese dos requisitos das entrevistas](sintese-requisitos-entrevistas.md). Cada aplicação usa uma cópia deste arquivo, com as respostas de uma pessoa. A disciplina pede duas aplicações, com pessoas diferentes da entrevistada.

Não preencher com o que Adriana Silveira de Souza já disse. O que interessa é o que esta pessoa faz e precisa no trabalho dela.

Função entra porque a entrega pede nome, função e telefone. Exemplos: gestor, analista de RH, colaborador.

## Como responder

Marque uma opção com `[x]` quando a pergunta for de escolha. Nas demais, escreva em **Resposta**. Se a pergunta não fizer parte do seu trabalho, escreva "não se aplica" e siga. Pode marcar mais de uma opção quando a pergunta disser isso.

O código entre parênteses, como `(E1-RF01)`, liga a pergunta à síntese. Quem responde pode ignorá-lo.
